Google OAuth Setup Guide

MetraScan includes real Google Identity Services (GIS). To connect your live Google Cloud credentials:

  1. Visit Google Cloud Console
  2. Create a new project (e.g. MetraScan Verification)
  3. Configure your OAuth Consent Screen (External)
  4. Under Credentials, click Create Credentials → OAuth client ID
  5. Select Web application
  6. Under Authorized JavaScript origins, add your local/deployed server URL:
    http://localhost:3000 or http://127.0.0.1:5500
  7. Copy your Client ID and open js/auth.js
  8. Replace GOOGLE_CLIENT_ID = "YOUR_GOOGLE_CLIENT_ID" with your Client ID
  9. Save and refresh the page!

See README.md for complete configuration instructions.

💡 How to Get a Successful Verification:
  • Flip to Back-of-Pack (BOP): Statutory declarations (MRP, Net Qty, Mfg Date) are printed on the back/side panel, not the front brand artwork.
  • Check Lighting & Glare: Foil or glossy plastic reflections can blind the OCR camera. Angle the package slightly away from direct reflections.
  • Align Inside Box: Use the live horizon level bar to hold the phone straight and bring the package close enough to fill the viewfinder.
